## 2. Как расшифрован эскиз (все размеры измерены попиксельно)

Масштаб эскиза определён по трём независимым замерам: **107.2 px/in**
(3.69 in = 396 px; 1.94 in = 208 px; 1.25 in = 134 px). 1 in = 25.4 мм.

| Размер на эскизе | Что это на самом деле | Проверка |
|---|---|---|
| **3.69 in** | сторона **вспомогательного** шестиугольника, описанного вокруг зубчатого венца | его вписанный радиус = 3.69·cos30 = **3.195 in** → радиус окружности вершин зубьев |
| **1.94 in** | радиус **вспомогательной** окружности C1 (на ней в чертеже построены касательные по 6 осям) | 1.94 + 1.25 = 3.19 in = 3.69·cos30 ✓ |
| **1.25 in** (радиальный, справа сверху) | расстояние C1 → окружность вершин зубьев | согласуется с 1.94 in и 3.69 in |
| **2.24 in** | сторона шестиугольника, описанного вокруг C1 | 2·1.94·tan30 = **2.24 in** (точно) |
| **1.25 in** (слева снизу) | **ширина спицы** (между двумя параллельными боковыми линиями) | 133 px на эскизе |

**Вывод:** три из пяти размеров (3.69 / 2.24 / 1.94 + 1.25 радиальный) относятся к
**конструктивной геометрии** чертежа — шестиугольнику и окружности C1. Размер, который
описывает саму деталь, — ширина спицы 1.25 in.

## 3. Как извлечены размеры из фото

Фото снято с перспективой (диск сплюснут по вертикали в 0.871 раза), поэтому фото
переведено в полярные координаты с исправлением искажения (`analyze_photo3.py`),
после чего сняты: число зубьев, глубина зубьев, радиус внутренней окружности обода,
радиус ступицы, диаметр отверстия.

| Параметр | Значение | Источник |
|---|---|---|
| зубьев | **51** (шаг 7.06°, автокорреляция + подсчёт по маске) | фото |
| профиль зуба | пилообразный, скруглённый, плоская вершина, узкий корень | фото (`tooth_template.py`) |
| корень зуба | 0.944 · R_верш | фото |
| внутренняя окружность обода | 0.807 · R_верш | фото |

Геометрия окна построена так, чтобы ширина спицы на окружности обода была ровно

### Расхождение между эскизом и фото (важно)
В эскизе внутренняя окружность обода = **C1 = 1.94 in (49.3 мм)**, т.е. обод почти вдвое
глубже, чем на готовой детали (**2.58 in = 65.5 мм**). Поэтому:

* `GearPart_v5.FCStd` — обод как на **фото** (R 65.5 мм) — соответствует указанию
  «за основу картинку»;
* `GearPart_v5_sketchrim.FCStd` — обод как на **эскизе** (R 49.28 мм), та же спица 1.25 in,
  окна уже (хорда 64.9 мм) — соответствует «основные размеры с наброска».

Переключение: `freecadcmd build_gear_part_v5.py sketch`.

## 6. Замечания

* Размеры на эскизе (1.94 / 2.24 / 1.25 радиальный) — это размеры **конструкции** чертежа,
  а не детали; в модели они сохранены как отдельные объекты `ConstructionCircle_C1`,
  `ConstructionHexagon`, `TipCircle` внутри документа.
* Модель построена полигональным контуром (зубья — по 48 точек на зуб, дуги — с шагом 1°),
  поэтому в документе ~3200 граней; отклонение от идеальных кривых < 0.01 мм.
  Для дальнейшего редактирования удобно снять фасетку через Shape→Fuse или
  перестроить контуры по параметрам скрипта.
* Предыдущие версии (`GearPart.FCStd`, `GearPart_v4.FCStd` — «сплошной шестиугольник с
  трехлопастным карманом») оставлены для сравнения, **актуальная — v5**.
