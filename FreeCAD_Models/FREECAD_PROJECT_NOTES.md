# Проект: Автономное создание чертежей FreeCAD по фото

## Архитектура
- **Среда:** VS Code с расширением Roo Code (Dev Container: Secure-Agent-Sandbox).
- **Модель:** Qwen 3.8 Flash (через OpenRouter).
- **Инструмент:** MCP-сервер `freecad` (запускается через `/home/igor/.local/bin/uvx freecad-mcp --only-text-feedback`).
- **FreeCAD:** AppImage 1.1.4 (запускается на хосте, не в контейнере).

## Ключевой вывод (обход ограничений)
Так как Roo Code работает в Docker-контейнере, а FreeCAD — на хосте, **GUI-инструменты MCP (create_document и т.п.) не работают** (порт 9875 недоступен из контейнера).
**Решение:** Использовать инструмент **`execute_code_headless`**. Он запускает `freecadcmd` в фоне, создаёт файл `.FCStd` и сохраняет его в рабочую область. Это самый надёжный путь.

## Правила и пути
- **Папка для сохранения:** Все файлы `.FCStd` по умолчанию сохраняются в `/workspace/FreeCAD_Models/`.
- **Правило Roo Code:** Создан файл `.roo/rules/freecad-save-path.md` с указанием пути сохранения.
- **Как открыть чертёж:** Файлы из контейнера нужно скачать (правой кнопкой -> Download) в `~/Downloads` на Linux и открыть в FreeCAD.

## Пример рабочего промпта для новой задачи
> Используй `execute_code_headless`. Создай 3D-модель по фото. Сохрани результат в `/workspace/FreeCAD_Models/Bottle.FCStd`. Если вылезут ошибки — исправь код и повтори.
